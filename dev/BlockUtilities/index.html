Utility functions for single blocks

These internal functions are the backend of Z2Block, Z2RowVecBlock and Z2ColVecBlock. They are unsafe, which means that they assume the blocks are of full size and do not check the validity of the arguments.

Z2Algebra.bitstringblock — Function
bitstringblock(x::Union{UInt64, Int64})

Convert a 64-bit integer to a block of bits in a human-readable format.

Example

julia> bitstringblock(TRIU_MASK) |> print
11111111
01111111
00111111
00011111
00001111
00000111
00000011
00000001

Z2Algebra.blockgetindex_mask — Function
blockgetindex_mask(i, j)

Get the mask where the bit(s) at 0-based position (i, j) in are 1. This function is low-level, and the caller is responsible for bounds checking.

Note

Unlike blockgetindex, this function does not shift bits to the least significant position.

source
Z2Algebra.blockgetindex — Function
blockgetindex(x::UInt64, i, j)

Get the bit(s) at 0-based position (i, j) in the block. This function is low-level, and the caller is responsible for bounds checking.

Note

Unlike blockgetindex_mask, this function shifts bits to the least significant position.
